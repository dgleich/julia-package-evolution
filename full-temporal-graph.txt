This is a directory with a study of the julia package dependnecies over time.
These are stored in two different repos. 
The changeover between the two repos occurs on 
- ## Registry Transition Details
- **Transition Date**: February 25, 2018 (commit `fdea9f164d45b616ce775e5506c0bbef70f3bb29`)
Both repos have been cloned in this particular directory, although that may 
not be the case for people who try to use the code.

The goal is now to produce a commit-by-commit analysis. the starting point
is to get a graph for each commit and allow us to see the changes 
between commits as well as the edits to each edges. 

This should be done in the following module, which we'll need you to create
code for. A skeleton is below.
